# TinyVoice Pi: Cascaded Voice‑Controlled IoT System

## Overview
TinyVoice Pi is a **three‑stage cascaded pipeline** that runs on a Raspberry Pi to provide low‑latency, on‑device voice control for IoT hardware. The pipeline consists of:
1. **Voice Activity Detection (VAD)** – Detects when a user starts speaking.
2. **Neural Speech Enhancer** – Denoises and enhances the captured audio using a lightweight speech‑enhancement model.
3. **TFLite Classifier** – Classifies the cleaned audio into a set of voice commands and triggers GPIO actions.

The system is completely offline, requires no cloud connectivity, and is tuned for the limited compute of a Pi.

---

## System Architecture
```
[Microphone] → VAD (live_server.py) → Speech Enhancer (pipeline.py) → TFLite Classifier (tflite_runner.py)
          │                │                         │
          └─► GPIO Control (gpio_control.py) ◄─────┘
```

* **live_server.py** – Captures audio chunks and runs the VAD.
* **pipeline.py** – Chains the VAD output to the speech‑enhancement model and forwards the waveform to the classifier.
* **tflite_runner.py** – Loads the TensorFlow‑Lite model, runs inference, and returns a command string.
* **gpio_control.py** – Maps command strings to GPIO actions (LED, Servo …).
* **tinyvoice_run_v2.py** – Convenience wrapper that starts the whole system with a single command.

## Hardware Pinout
| Component | GPIO Pin | Physical Pin |
|-----------|----------|--------------|
| LED (status) | **GPIO 23** | Pin 16 |
| Servo Motor | **GPIO 12** | Pin 32 |

> **Tip:** Remember to enable the GPIO pins in the Pi’s `config.txt` if you are using a headless setup.

## Installation
```bash
# 1️⃣ Clone the repository (or copy the folder to your Pi)
git clone https://github.com/YOUR_USERNAME/tiny-voice.git
cd tiny-voice

# 2️⃣ Install system dependencies (Raspberry Pi)
sudo apt‑update && sudo apt‑install -y python3-pip python3-venv libatlas-base-dev

# 3️⃣ Create a virtual environment and install Python packages
python3 -m venv venv
source venv/bin/activate
pip install -r requirements-pi.txt

# 4️⃣ Verify GPIO permissions (run as sudo or add user to gpio group)
sudo usermod -aG gpio $USER  # then re‑login
```

---

## Running the Application
```bash
# Activate the virtual environment if not already active
source venv/bin/activate

# Start the cascaded voice‑controlled system
python tinyvoice_run_v2.py
```
The script will:
1. Initialise the microphone.
2. Continuously listen for voice activity.
3. Enhance the audio, classify it, and execute the mapped GPIO action.
